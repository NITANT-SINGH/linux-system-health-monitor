
# Linux System Health Monitor

## Project Status
In progress.

## Objective
Build a Bash script that checks basic Linux system health and
reports useful information for troubleshooting.

## Planned Features
- Display system uptime
- Report memory usage
- Report disk usage
- Check selected system services
- Display warnings when usage exceeds configurable thresholds

## Requirements
- Linux
- Bash
- Standard Linux command-line utilities

Instructions will be added after the script is implemented and tested.
